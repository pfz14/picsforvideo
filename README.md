<details>
<summary>给自己的备忘：怎么往里放图 / 加新视频</summary>

**放图**：在 GitHub 网页上点进对应的文件夹（比如 `BV1Hzpm6hEaY-您的账号已被封禁/角色`）→ 右上角 **Add file → Upload files** → 把图拖进去 → 拉到最下面点绿色的 **Commit changes**。

**加新视频**：让小克按 BV 号建文件夹、更新上面的表就行。

规矩：一张图只放一个地方；好几支视频都用的放「共用设定稿」；尽量放原图。
